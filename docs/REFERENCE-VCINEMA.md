# 参考站拆解：南瓜电影（v.vcinema.cn / 南心电影）与人人视频

> 目的：把两个成熟站的**结构**抄到位，而不是自己拍脑袋设计。本文只记录可观测到的事实（页面文案、交互、字段），以及影巢对应的落地状态。
> 观测方式：ego-browser 匿名访问（`v.vcinema.cn` 未登录状态），2026-11-10。

## 1. 顶部导航（南瓜电影只有 5 项）

| 南瓜电影 | 影巢 |
| --- | --- |
| 首页 / 电影 / 剧集 / 筛选 / 我的片单 | 精選 / 分类 / 电影 / 电视剧 / 美剧 / 韩剧 / 日剧 / 英剧 / 短剧 / 动漫 / 综艺 / 纪录片 / 即将上线 / 片单广场 / 9 个榜单 / 历史·收藏 |
| 右侧：搜索框（占位「输入电影名、国家、演员…」）+ 收藏图标 + 消息铃 + 头像 | 搜索框 + 历史/收藏/消息/会员 + 登录按钮 |

结论：**主站把长尾收进「筛选」，导航只留 5 项**。影巢侧栏 24 项虽然找得到，但视觉噪音大；下一步应把「美剧/韩剧/日剧/英剧」这类地区快捷入口从侧栏撤掉，只留频道 + 榜单分组。

## 2. 筛选页（`/filtrate`）结构与文案

```
全部影视   电影   电视剧
综合排序   最新上线   热播   流行   南瓜评分
全部类型   动作 战争 科幻 冒险 犯罪 灾难 魔幻 悬疑 剧情 恐怖 西部 喜剧 动画 纪录片 奖项
全部地区   中国 美国 英国 法国 亚洲 德国 俄罗斯 加拿大 意大利 西班牙 澳大利亚 其他
全部年份   2026 2025 2024 2023 2022 2021-2017 2016-2012 2011-2000 90年代 80年代 其他
```

- 版式：左侧固定行标签（灰），右侧纯文本选项横排；**选中项橙色加粗，没有底色和描边**。
- 结果区：7 列海报网格，无限滚动；海报左上角「最新上线 / 独播」角标，右下角评分（橙色数字）。
- 列表卡（横排推荐位）展开信息为：`评分 · 国家｜年份｜时长｜语言` + 一句话卖点（如「退役特工 重返江湖」）。

影巢现状：维度已 1:1（频道/排序/地区/类型/年份/标签），本轮把胶囊样式改成同样的「行标签 + 纯文本选中」，海报补了角标与右下评分。

## 3. 首页

- Hero 大图轮播：标题 Logo + 简介 + 金色角标（如「2026年动画片内地票房冠军」）+ `播放` + `＋`（加入片单）。
- 楼层：`精彩佳片`、频道楼层（电影/剧集），每层横排大卡（带评分/国家/年份/时长/语言）。
- 广告位：右下浮层（「短剧推荐官」）与信息流卡（「免费小说」）——**营销位是显式的，且可关闭**。

## 4. 详情 / 播放页

左侧播放器，右侧信息栏三个 tab：`详情 | 相关资讯 | 影评 65条`。

详情栏内容：标题 → 卖点行（带图标徽标）→ 简介 → `主演：…` `导演：…` → 三个动作 `＋ 添加片单 | ♡ 喜欢 | ♡ 不喜欢` → `类似影视`（竖排卡，带时长/地区/年份/语言）。

播放器（自动起播）：
- 试看文案：**「试看 10:00 后结束，观看完整影片请 登录」** —— 试看 10 分钟，然后登录墙。
- 工具条：后退 10s / 前进 10s / 弹幕开关 / 弹幕设置 / **发弹幕输入框 + 发送** / 音量 / 清晰度 / 全屏 / 更多。

影巢现状：试看倒计时（本轮改成「试看剩余 mm:ss」）、弹幕渲染、播放错误自愈都有；缺 `影评/资讯` tab、`喜欢/不喜欢`、`类似影视`（本轮已加）。

## 5. 登录与付费

登录弹窗三合一：**短信验证码（默认）/ 密码 / 扫码（客户端）**，左侧挂二维码并写「新用户专享免费七天试用服务」，底部「登录即表示您同意 服务条款 和 隐私政策」。

- 南瓜电影是**纯会员制**：没有单片付费入口、没有金币/券的页面痕迹，靠「7 天免费试用 → 连续订阅」拉新。
- 影巢是**会员 + 单片 + 按集规则**三合一（更灵活），但营销侧几乎没有：没有试用、没有首单券、没有到期提醒弹窗。本轮补了「会员卡剩余天数」。
- 页脚客服：`官方客服热线 400-699-6228`、`hello@vcinema.cn` —— 影巢只在登录失败文案里提「联系客服」，页脚没有电话/邮箱，需要在页脚与登录弹窗补齐。

## 7. 仍未做（按价值排序）

1. **详情页 `影评` tab**：库里有 `comments` 表 + 后台审核队列，C 端零接口。要开 `GET/POST /api/drama/:id/comments` 与详情页 tab。
2. **`相关资讯` tab**：需要内容运营（图文资讯表），短期内可先接「同标签剧集」占位，但要标明是推荐不是资讯。
3. **喜欢 / 不喜欢**：给推荐算法用的二值反馈，落 `reactions(user_id, drama_id, value)`，能直接喂 HOT 榜权重。
4. **新用户 7 天试用**：影巢可做「注册即送 7 天会员」试用券，转化钩子；需要 `trial_subscriptions` 或复用 `coupons` 的 0 元券。
5. **页脚客服信息**：电话 + 邮箱 + 服务条款/隐私政策链接。
6. **导航瘦身**：侧栏从 24 项缩到「频道 8 项 + 榜单可折叠 + 我的」。
