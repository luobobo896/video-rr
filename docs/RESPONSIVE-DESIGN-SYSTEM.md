# 影巢 C/B 端响应式设计系统

> 依据：UI UX Pro Max（Accessibility / Touch / Performance / Layout 优先级）+ 项目前端规则 + `DESIGN.md` 既有令牌。
> 目标：手机、iPad、安卓平板、PC 四类终端共用一套几何令牌；不按 UA 嗅探，按可用视口宽度切换布局。

## 1. 设计原则

1. **内容优先**：核心内容与主操作永远不被次级按钮挤出视口。
2. **单行优先**：标题、按钮、操作项、关键状态默认单行；空间不足用省略/折叠，不自然换行。
3. **内部滚动**：页面本身禁止横向滚动；表格、筛选项、长导航只在自身滚动容器内横滑。
4. **触控优先**：手机上所有可点区域 ≥44×44px；相邻触控目标间距 ≥8px。
5. **状态可感知**：异步按钮必须有加载、禁用、成功/失败反馈，不允许“点了没反应”。
6. **布局稳定**：异步刷新只更新目标数据，不整页重绘；按钮、状态位预留宽度。
7. **颜色可读**：正文对比度 ≥4.5:1；品牌按钮使用深色 `--brand-contrast`，不再使用低对比白字。

## 2. 断点定义

实现基于 `max-width` 查询，但设计按终端语义分组：

| 终端 | 视口宽度 | 导航 | 页面边距 | 内容最大宽度 |
|---|---:|---|---:|---:|
| 手机 | 320–599 | C/B 顶部或底部固定导航 | 16px | 100% |
| iPad | 600–1023 | C 底部 5 入口；B 顶部横向菜单 | 24px | 100% |
| 安卓平板 | 600–1199 | 与 iPad 共用平板规则；1024+ 仍保持平板导航 | 24px | 100% |
| PC | ≥1200 | C 左侧 124px；B 左侧 210px | 32px / 26px | C 1600px；B 1680px |

补充：

- iPad 与安卓平板共用 600–1199 断点，不做设备识别，减少两套布局的维护分叉。
- 1599px 以上 C 端 6 列，1200–1599 为 5 列。
- 360px 以下海报降为 2 列；361–599 为 3 列。
- 手机 + 平板底部导航 = 48px + `env(safe-area-inset-bottom)`。
- 顶部栏/页面内容/底部导航均处理 `env(safe-area-inset-left/right)`，覆盖横屏刘海与圆角屏。

### 2.1 C 端栅格

| 视口 | 海报列数 | 页面边距 | 说明 |
|---|---:|---:|---|
| ≥1600 | 6 | 32 | 宽屏影院排布 |
| 1200–1599 | 5 | 32 | 标准 PC |
| 1000–1199 | 5 | 24 | 平板横屏/紧凑桌面 |
| 600–999 | 4 | 24 | iPad / 安卓平板 |
| 400–599 | 3 | 16 | 手机 |
| ≤360 | 2 | 16 | 小屏手机 |

### 2.2 B 端栅格

- PC：`auto-fit / minmax(160px, 1fr)`，概览卡片约 4–6 列。
- 平板：固定 3 列指标卡。
- 手机：2 列；≤359px 为 1 列。
- 表格：容器最小宽 760px，由 `.panel` 内部横滑，页面 `scrollWidth` 不得超过 `clientWidth`。

## 3. 导航布局

### C 端

- PC：左侧 124px 固定侧栏；一级分组标题 15px/600，二级菜单项高 40px、字号 14px/400，2/3/4 字标签左缘对齐；激活项自动滚入可视区。
- 侧栏只保留频道入口、单一「榜单」入口与「历史 / 收藏」，不在左栏平铺 9 个子榜单。
- 平板/手机：底部 5 个高频入口：精选、分类、电影、榜单、我的。英文模式使用短标签 `Home / Browse / Wall / Ranks / Me`，不直接复用桌面侧栏的长标签，避免 320–390px 下五个入口相互重叠。
- 其余频道在“分类”页的频道筛选中可达，不占用底部导航。
- 顶部四个次级动作（历史/收藏/消息/会员）在平板和手机隐藏；登录/账号按钮保留。
- ≤599px 时顶栏换行：第一行保留品牌、语言切换和登录，搜索框独占第二行；搜索输入字号 16px，避免 iOS 聚焦缩放，也不因语言名称变长而把输入框挤成 0 宽。

### B 端

- PC：左侧 210px 侧栏；`#nav` 独立纵向滚动，底部账号动作不随菜单滚动。
- 平板/手机：侧栏变为顶部粘性横向菜单，分组可折叠，菜单自身横滑。
- 页面标题、更新时间、快捷入口允许换行成两行，但主标题保持单行省略。

### z-index 层级

| 层级 | 值 | 用途 |
|---|---:|---|
| 粘性顶部栏 | 20 | C 端 topbar |
| 移动/平板导航 | 40–60 | B 顶栏、C 底栏 |
| 弹窗 | 60 | 登录、付费墙、编辑弹层 |
| 提示 | 80–99 | toast |
| 路由加载条 | 200 | 页面切换进度 |

## 4. 间距系统

基础单位：**4px**。

| Token | 值 | 用途 |
|---|---:|---|
| `--sp-1` | 4px | 图标与文字、紧凑标签 |
| `--sp-2` | 8px | 相邻按钮、卡片内小间距 |
| `--sp-3` | 12px | 表单控件、列表项 |
| `--sp-4` | 16px | 卡片内边距、手机页面边距 |
| `--sp-5` | 24px | 平板页面边距、区块内间距 |
| `--sp-6` | 32px | PC 页面边距、区块间距 |

规则：

- 同一容器只使用相邻两档间距，不出现 13/17/21 等随机值。
- 按钮组、操作组优先 `gap: 8px`；手机触控组不小于 8px。
- 区块之间 C 端 32–34px；B 端 panel 之间 16px。

## 5. 字体与颜色

### 5.1 字体

- 正文：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", system-ui`。
- 数字/订单号/技术字段：`ui-monospace, "Cascadia Code", Consolas, monospace`。
- 不引入远程 Web Font，避免慢链路 FOUT/CLS。

| 层级 | PC | 平板/手机 | 行高 | 字重 |
|---|---:|---:|---:|---:|
| 页面标题 | 30–34 | 26–28 | 1.2 | 800 |
| 区块标题 | 19 | 18 | 1.25 | 700 |
| 组件标题/按钮 | 14 | 14 | 1.2 | 600 |
| 正文 | 14 | 14–15 | 1.6–1.75 | 400 |
| 辅助信息 | 12 | 12 | 1.45 | 400 |
| 角标 | 10–11 | 10–11 | 1.2 | 600 |

手机端输入框字号固定 16px，避免 iOS 聚焦自动放大；播放器工具条也遵循此规则。

### 5.2 颜色与对比度

- C 端品牌：`#ff3d6e → #ff7a45`；品牌按钮文字使用 `--brand-contrast: #241000`。
- B 端品牌：`#4f7cff → #22d3ee`；品牌按钮文字使用 `#06121a`。
- 三级文字统一提升为 `#8a93a5`，在 C 端深底约 6.4:1，在 B 端面板约 5.75:1。
- 正文字号小于 18.66px 且非粗体时，颜色对比度必须 ≥4.5:1。
- 颜色不是唯一状态提示：成功/失败同时提供文字与图标/状态点。

## 6. 组件规范

### 6.1 按钮

| 尺寸 | 高度 | 横向 padding | 圆角 | 字号 | 使用 |
|---|---:|---:|---:|---:|---|
| sm | 32 | 12 | 8 | 13 | 表格行内、桌面工具栏 |
| md | 40 | 18 | 10 | 14 | 默认操作 |
| lg | 48 | 24 | 14 | 16 | 登录、付费墙主 CTA |

- 手机触控高度不足 44px 时，用 `min-height:44px` 扩展点击区，不改变视觉高度。
- 状态：默认 / hover（颜色/亮度）/ active（下移 1px）/ disabled（opacity .45）/ loading（禁用 + spinner + 文案“处理中…”）。
- 危险操作只用描边危险色，不使用品牌渐变。
- 同一操作区最多 1 个主按钮；其余用次要/文字按钮。
- 图标按钮：24px 图标 + 44×44 点击区；新组件使用内联 SVG，不用 emoji。

### 6.2 输入框与选择器

- 高度：32 / 40 / 48；水平 padding 12；圆角 8 / 10 / 14。
- 手机输入框字号 16px；桌面 13–14px。
- 聚焦必须有 2px 品牌光环；禁止 `outline:none` 后不加替代。
- 错误态：危险色描边 + 文案 + `aria-invalid="true"`。
- 原生 select 统一 `appearance:none` 并自绘箭头。

### 6.3 卡片与列表

- 海报卡固定 2:3 比例，图片 `object-fit:cover`，`loading="lazy"`；标题/副标题单行省略。
- B 端指标卡高度由内容决定，但同组卡片使用同一最小高度。
- 列表行使用 `min-width:0`，标题可省略，辅助信息可折叠；不允许撑破父容器。

### 6.4 弹窗

- 宽度：`min(420–760px, calc(100vw - 32px))`。
- 手机最大高度 `calc(100dvh - 24px)`，内容区独立滚动，header/footer 固定。
- 打开后焦点进入弹窗，Esc/遮罩关闭；关闭后焦点回触发按钮。

### 6.5 标签与状态

- 标签圆角 999px，高度 24–28px，字号 11–12px。
- 成功/警告/危险同时使用颜色 + 文本；不允许只靠颜色区分。
- 长标签单行省略，完整值放 `title` 或详情。

### 6.6 分页

- 服务端分页列表必须返回 `page/pageSize/total`；完整数组列表由前端统一分页，不得用 `slice(0,N)` 静默截断。
- 分页器必须显示“共 N 条 · 第 X / Y 页”、上一页、下一页和数字页码；超过 7 页时保留首尾页与省略号。
- PC 按钮 32px；手机最小 44px。
- 首页/末页按钮禁用而不是隐藏，避免布局跳动。

### 6.7 提示与反馈

- 成功：toast + 行内状态；失败：toast + 明确错误原因 + 重试入口。
- toast 最大宽 `100vw - 32px`；C 端在底部导航上方显示。
- 异步页面切换显示顶部 2px 进度条；保留旧内容不可交互时设 `aria-busy="true"`。

## 7. 排版、换行与溢出策略

### 7.1 单行规则

以下内容必须单行：

- 页面/区块标题；
- 按钮文字、操作项；
- 导航项、分页；
- 表格关键 ID/金额/状态；
- 播放器标题与清晰度。

超出时：

1. 优先截断 + `text-overflow:ellipsis`；
2. 提供 `title` 或详情查看完整内容；
3. 不通过减小字号到 10px 以下来硬塞。

### 7.2 可换行内容

- 长描述、简介：最多 2 行 clamp，详情页可完整展开。
- 标签组、演员 chips：允许换行，但每行内部不撑破容器。
- 表单错误、帮助文字：允许换行，行高 ≥1.5。

### 7.3 表格

- 页面不横滑；表格放在 `overflow-x:auto` 容器内。
- 手机上的表格最小宽 760px，列宽由内容决定；常用列靠左。
- 操作列固定在最后一列，行内按钮不换行；次要操作可收纳到“更多”。

### 7.4 图片

- 海报固定 2:3，banner 固定 16:9 或明确宽高比；
- 使用 `srcset/sizes` 或至少按终端提供 480/720/1080 版本；
- `object-fit:cover` 用于海报，`contain` 用于视频；
- 始终预留宽高，避免刷新/懒加载引起 CLS。

### 7.5 溢出验收

- 页面级：`document.documentElement.scrollWidth <= clientWidth`。
- 容器级：所有内部横滑容器的 `scrollWidth > clientWidth` 是预期行为，但不得把父级撑宽。
- 必须测试 320 / 375 / 390 / 768 / 820 / 1024 / 1199 / 1200 / 1366 / 1440 / 1600 / 1920。

## 8. C 端与 B 端差异

| 维度 | C 端 | B 端 |
|---|---|---|
| 信息密度 | 低，强调海报与内容 | 高，强调表格、指标、状态 |
| 导航 | 内容消费型，底部 5 入口 | 功能型，分组菜单 + 横向平铺 |
| 主色 | 粉/橙品牌色 | 功能蓝/青 |
| 主操作 | 免费播放、购买、收藏 | 保存、上架、刷新、审核 |
| 次级操作 | 分享、榜单切换 | 删除、导出、高级筛选 |
| 手机策略 | 隐藏顶部次级动作，保留播放/购买 | 表格内部横滑，操作列靠后 |
| 平板策略 | 4–5 列海报 | 3 列指标卡，菜单顶部横滑 |

### 常用操作优先级

- C 端手机：播放/免费看 > 购买 > 收藏/分享 > 榜单切换 > 其他。
- C 端平板/PC：播放/购买 > 搜索 > 分类/榜单 > 收藏/分享。
- B 端手机：刷新/保存/上架 > 搜索 > 编辑/分集 > 删除/导出。
- B 端 PC：刷新/保存/上架 > 批量操作 > 筛选 > 导出/删除。

## 9. B 端“刷新素材”刮削按钮

### 位置

- `内容运营 → 剧集管理` 面板标题右侧。
- 位于搜索框与“新建剧集”之间；移动端随标题换行，不悬浮覆盖表格。

### 视觉与状态

| 状态 | 表现 |
|---|---|
| 默认 | SVG 刷新图标 + “刷新素材”，40px 高，最小宽 132px；状态行显示“素材同步就绪” |
| 加载 | 禁用、`aria-busy="true"`、图标旋转、文案“刮削中…” |
| 成功 | 行内绿色状态“更新 N 部 · 横幅 +M”，toast 同步 |
| 部分失败 | 黄色状态“更新 N 部 · 横幅 +M · 失败 K”，toast + console 详情 |
| 完全失败 | 红色状态“刮削失败，请稍后重试”，toast 错误原因 |

### 交互规则

1. 点击后立即 `disabled`，并用 `dataset.busy` 做二次防重。
2. 请求期间不整页重绘；只更新目标封面单元格，按钮宽度固定，状态位于独立 `aria-live="polite"` 区域，默认占位避免出现/消失造成抖动。
3. 成功后只替换对应封面 `<img>`，表格行高、列宽、滚动位置保持不变。
4. 结果包含更新数、banner 新增数、失败数；失败详情写入 console，不阻塞页面。
5. 页面离开时请求由路由 AbortController 取消。
6. 触控端按钮高度 44px，加载态仍保留关闭/其他操作可点。

### 接口

`POST /admin/api/artwork/refresh`

```json
{
  "limit": 100,
  "bannerLimit": 6
}
```

响应：

```json
{
  "total": 5,
  "updated": 3,
  "failed": 0,
  "banners": { "created": 2 },
  "details": [
    { "id": 1, "title": "咖啡跑", "cover": "/media/images/cover-coffee.jpg", "ok": true }
  ]
}
```

## 10. 实现映射

- 全局令牌：`shared/tokens.css` → `node scripts/sync-tokens.mjs`
- C 端布局：`public/styles.css`
- C 端导航/路由/状态：`public/app.js`
- B 端布局：`admin/styles.css`
- B 端列表/刮削按钮：`admin/app.js`
- 刷新 API：`server/api-admin.mjs` → `server/artwork.mjs`
