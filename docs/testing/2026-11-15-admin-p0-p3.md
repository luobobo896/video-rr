## 边界

- `npm run test:admin:browser` 需要本地已启动后台、提供测试账号，并安装 ego-browser；它不加入默认 `npm test`，避免普通单测依赖浏览器。
- 本次只迁移用户、订单两个通用列表。其余旧列表仍由 `admin/app.js` 渲染，后续新增列表应优先使用 `AdminDataTable.vue`。
- 没有数据库迁移，回滚只需还原本次代码和文档。
