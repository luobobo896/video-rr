# 2026-11-11 前端审计与可访问性收敛

## 范围

C 端 `public/` 与后台 `admin/`。覆盖首页、分类、榜单、搜索、详情、登录弹层、个人中心和后台概览、剧集、策略、订单、用户页面，以及两端表单弹层。浏览器实测宽度为 375 / 390 / 768 / 1024 / 1440。

## 本轮修复

- 弹层：C/B 两端统一补齐 `role="dialog"`、`aria-modal`、标题关联、初始焦点、Tab 循环、Esc 关闭、关闭后回焦和背景 `inert`。
- 图标：C 端顶栏、播放/收藏/分享/刷新等操作统一为 16px 线性 SVG；后台侧栏按要求只显示文字，不显示装饰图标。
- 对比度：修正海报角标、Hero 标签、锁定集数、加载骨架和三级文字；品牌渐变上的文字使用 `--brand-contrast`。
- 响应式：C 端移动端主按钮、筛选选项、选集按钮和 Logo 触控高度提升到 44px；分类筛选行和后台移动导航补横向滚动提示；后台剧集表格在窄屏转为卡片式布局。
- 首页：补齐新增轮播/滑轨/宽卡所需样式，修复移动端 Hero 图片未铺满和操作按钮换行的问题。
- 语义：C 端各页面补齐唯一 `h1`、区块 `h2`、`aria-current` 和表单可访问名称；后台恢复 `h1 → h2 → h3` 层级。
- 浏览器表面：两端补 `:focus-visible`、`::selection`、`caret-color`、滚动条配色和跳转主内容按钮。
- 个人中心：资料卡改为整行宽度，桌面两列字段、移动单列；邮箱独占整行，解决长邮箱与操作按钮互相挤压。
- 详情标签：≤1199px 允许长标签换行，避免长标签把后续标签顶出可视区。
- 账户导航：观看历史、我的收藏改为独立路由和页面；个人中心订单改为全宽列表/表格，修复 `amount_cny` 与 `amount` 字段错配导致的 `¥NaN`。
- 播放页：≥1024px 选集固定在右侧，手机和平板窄屏回到底部；播放键恢复 74px 圆形。
- 首页宽卡：缩短底部渐隐范围，减少整块黑底，图片与卡片信息重新平衡。
- 筛选：分类页横向筛选条在重绘后恢复 `scrollLeft`，点击远端标签后停留在当前标签。
- B 端：侧栏移除装饰图标，角色权限改为角色列表 + 权限树双栏布局，控制台卡片改为四列栅格。
- 日期：个人资料生日改为暗色 `color-scheme` + 主题日历图标，与表单控件统一。
