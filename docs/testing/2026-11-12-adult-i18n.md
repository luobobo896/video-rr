# 成人页面中英文切换修复

日期：2026-11-12

## 问题

切换到英文后，成人页面仍会出现中文：标签名、发行/更新时间、收藏与浏览统计，以及切回中文后部分 API 枚举标签没有即时更新。

## 根因

- `/api/home`、`/api/category`、`/api/tags` 等公开接口按 `x-mh-lang` 返回不同文案，但响应没有 `Vary`，前端请求 URL 也不带语言，浏览器缓存会复用中文响应。
- 成人标签接口对 `scope=adult` 直接返回 `tag.name`，默认中文标签没有英文映射。
- 成人卡片统计位于 `.card-sub`，该节点被 DOM 翻译器跳过；详情统计和发行信息也没有显式翻译。

## 修复

- 前端 API 请求追加 `lang` 查询参数；服务端公开缓存响应增加 `Vary: x-mh-lang`。
- 默认成人标签增加英文映射，`/api/tags?scope=adult` 和剧集详情的 `tags[].label` 返回当前语言。
- 成人卡片统计、详情统计、发行/更新时间、选集提示和剧集悬停文案改用 `t()`。

## 验证

- 分别对 `public/app.js`、`public/i18n.js`、`server/api-public.mjs`、`server/i18n.mjs`、`server/adult-taxonomy.mjs` 执行 `node --check`：通过。
- `npm run check:frontend`：10 个前端文件通过。
- `node --test "test/*.test.mjs"`：153/153 通过。
- 本地构建产物实测：
  - 中文/英文连续切换后，首页横幅类型和地区即时变为 `TV Series · South Korea`。
  - 成人列表标题、排序、8 个标签组和 111 个标签全部显示英文。
  - 成人卡片统计显示 `Released 2026-01-02 · Favorites 0 · Views 1`。
  - 成人详情显示 `Released / Updated / Favorites / Today / This week / This month / Total views`，选集提示为 `Unlock required to watch`。
  - 切回中文后标签恢复中文，再切英文恢复英文。

## 说明

- 内容标题、简介和用户输入的标签属于内容元数据，不做机器翻译；后台自定义中文标签没有英文映射时保留原值。
- `npm run check` 仍会因现有 `admin/tokens.css` 与 `shared/tokens.version.json` 的令牌漂移在 `check:tokens` 阶段失败；本次未修改令牌文件。
