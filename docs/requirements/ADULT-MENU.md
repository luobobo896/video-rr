# 成人菜单与影剧导入

## 目标

- C 端新增独立成人菜单，桌面侧栏和移动底栏使用后台配置的中英文标签。
- 点击成人菜单或直达成人内容时显示会话级年龄确认。
- 成人标记内容只进入成人列表，不出现在普通首页、分类、搜索、榜单、海报墙和内容榜。
- 后台支持本地文件与 HTTP(S) 视频直链两种片源添加方式。

## 行为

- 年龄确认文案：中文“是否年满18岁”，英文“Are you 18 or older?”。
- 确认后写入当前标签页的 `sessionStorage`；关闭标签页后重新确认。
- 点击菜单时取消留在原页面；直接访问成人路由时取消返回首页。
- 用户自己的历史、收藏和订单保留成人记录，进入详情或播放时仍经过年龄确认。
- 成人菜单关闭只隐藏入口和成人列表，不删除已标记内容；直达内容仍要求年龄确认。

## 内容规则

- `dramas.is_adult=1` 表示成人内容；默认 0，既有内容不受影响。
- 普通内容查询统一要求 `is_adult=0`；成人列表要求 `is_adult=1`。
- 成人剧集的相似推荐只返回其他成人内容。

## 片源导入

- 本地上传沿用 `POST /admin/api/episodes/:id/upload`。
- URL 导入仅接受 HTTP(S) 公开视频直链单文件，不解析网盘或网页。
- 服务端下载后执行 `ffprobe`，确认视频流后复用现有 HLS 转码队列。
- 下载上限复用 `MH_UPLOAD_MAX_BYTES`（默认 2GB），超时默认 15 分钟，最多 3 次重定向。
- 拒绝私网、回环、链路本地、带账号密码、非 HTTP(S) 和私网 DNS 解析结果。

## 风险与边界

- 年龄门禁是前端确认，不是实名或 KYC 验证，直接调用 API 仍可绕过。
- URL 导入是同步请求，不提供断点续传；失败后需重新提交。
- DNS 校验与真实连接之间仍存在极小重绑定窗口，当前只允许登录后的内容运营调用。
- `198.18.0.0/15` 不按私网拦截：本机开发环境的透明公网出口会使用该测试网段；其余私网、回环、链路本地、CGNAT 和组播地址仍拒绝。
- 运营方需自行确认外部 URL 的版权、授权与可下载性。
