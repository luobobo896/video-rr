影巢 · 组件规范

C 端（内容消费）与 B 端（运营台）共用一套组件几何：高度、圆角、字号、间距、描边完全一致，只有品牌色按端区分。 唯一来源是 shared/tokens.css，两端文件由 node scripts/sync-tokens.mjs 生成，禁止手改产物。

01尺寸体系

控件高度只有三档：--h-sm 32 / --h-md 40 / --h-lg 48。 默认（md）用于所有主要操作；sm 只用于表格行内、工具栏、二次确认等密集区域；lg 用于登录页、付费墙等单任务场景。 横向内边距按尺寸递进：12 / 18 / 24；输入框统一 12（按钮需要更强的视觉重量，所以比输入框宽）。

03输入框：三档尺寸 × 六种状态

原生 <input> / <select> / <textarea> 与自定义容器（付费墙、播放器工具条、表格行内编辑、树工具栏） 全部映射到同一组类与几何：高度 40（密集区 32）、左右 12、圆角 10、1px 描边、聚焦 2px 品牌光环。原生 select 的浏览器箭头已被统一替换。

04一致性约束

规则说明
同组件同几何两端、所有页面的按钮/输入框只允许 32/40/48 三档，不允许出现 34px、29px 这类中间值
一页一个主要按钮付费墙、登录页、编辑弹窗各只有一个 .btn.primary
输入框不改宽宽度由布局决定（width:100% 或容器宽度），不写死像素，除非是搜索框/验证码这类定长
原生与自定义对齐自定义容器（如带图标的输入框）内部原生 input 必须 height:100%; border:0; background:transparent，外壳承担描边与圆角
状态语义统一聚焦=品牌色、错误=危险色、禁用=opacity .55，任何页面都不例外
禁用必须给原因按钮禁用时旁边要有文字说明（如"请先选择分集"），不能只有灰按钮
触控最小 40C 端移动端可点区域不小于 40×40；表格内的 sm 按钮在移动端自动升为 md
立即播放 保存

左边三个来自改造前的旧样式：height 34 / padding 10×22 / radius 999、height 28 / padding 4×9 / radius 4、height 29 / padding 6×8。 同类控件出现 28、29、32、34、40 五种高度，用户在不同页面点击手感不一致，也是"看起来像两个产品拼起来"的根因。

05两端只差品牌色

同一套几何、同一套状态语义；C 端用暖红（内容消费、情绪化），B 端用功能蓝（长时间操作、需要冷静）。 --brand / --brand-2 / --brand-contrast 三个令牌是唯一允许分端定义的颜色。
